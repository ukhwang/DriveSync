# 예비 인터뷰 가이드 (~11/23)

대상: 차로 거래처를 도는 현직자 5명 이상 (제약·의료기기 영업, 보험 설계사, B2B 솔루션 영업). 인당 20~30분.

인터뷰 기록에는 이름·회사명 대신 `P1`, `P2` 같은 코드만 씁니다. 동의 없이 녹음하지 않습니다.

## 확인할 4가지 (기획서 0)

1. **하루 방문 수**: 어제 몇 곳을 방문하셨나요? 평소에는요? 이동 시간은 한 번에 얼마나 걸리나요?
2. **방문 후 기록 시점과 방식**: 마지막 방문 기록은 언제, 어디서, 무엇으로 남기셨나요? (차 안 / 사무실 / 퇴근 후, CRM / 메모앱 / 카톡)
3. **후속 연락 누락 경험**: 최근 한 달 사이 약속한 후속 연락을 늦게 하거나 놓친 적이 있나요? 그때 무슨 일이 있었나요?
4. **비용 지불 주체**: 업무 도구 비용은 누가 내나요? 회사가 도구를 도입할 때 누가 결정하나요?

## 추가로 볼 것

- 운전 중에 떠오른 생각을 지금은 어떻게 처리하나요? (음성 메모, 정차 후 메모, 그냥 잊음)
- 미팅 직전 차에서 무엇을 확인하나요? 얼마나 걸리나요?
- 승인 없이 AI가 메일을 보낸다면 어떻게 느낄까요? (승인형 실행 가설 확인)
